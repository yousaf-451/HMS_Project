🏥 HMS — Hospital Management System

The app now uses a real database (SQLite) through a small Python server, so it must be started first.

Start it (pick one)

  1. VS Code: open this folder, press Ctrl+Shift+B (or Terminal → Run Build Task).
  2. Windows: double-click start_hms.bat
  3. Mac: double-click start_hms.command   Linux: run ./start_hms.sh
  4. Any terminal in this folder: 
    python server.py
    (Windows: py server.py, Mac/Linux: python3 server.py)

Your browser opens http://localhost:8000. Login: admin@hms.test / Admin@123

Needs Python 3.8 or newer. Nothing else to install.

Open http://localhost:8000 (works once the server is running)
